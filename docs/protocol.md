# UART 二进制通信协议

## 1. 协议用途

本协议用于定义 QEMU 中运行的 Cortex-M4 嵌入式控制端
与 Python / PyBullet 机器人仿真端之间的二进制通信格式。

通信链路主要支持：

- 六轴关节目标角下发
- 六轴关节状态反馈
- 基本数据帧校验
- 后续其他控制命令扩展


## 2. 数据帧格式

每个数据帧采用以下结构：

| 字段 | 长度 | 说明 |
|---|---:|---|
| 帧头 Header | 2 字节 | 固定为 `0xAA 0x55` |
| 命令 Command | 1 字节 | 表示消息类型 |
| 长度 Length | 1 字节 | Payload 的字节数 |
| 数据 Payload | N 字节 | 与具体命令相关的数据 |
| 校验 Checksum | 1 字节 | Command、Length 和 Payload 的字节和取低 8 位 |

数据帧结构：

```text
+--------+---------+--------+-------------+----------+
| Header | Command | Length |   Payload   | Checksum |
+--------+---------+--------+-------------+----------+
| 2 byte | 1 byte  | 1 byte |   N byte    | 1 byte   |
+--------+---------+--------+-------------+----------+
